A deterministic Node program that writes one line — the funniest excuse an AI
agent gives its human for missing a deadline — to `/output/entry.txt`.

Entry: "Sorry — I hallucinated a deadline extension, believed myself, and only checked the calendar after celebrating."

Run it with:

```sh
node main.ts
```
